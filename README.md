# pg-puffinhale — 吸吐清波

原創泡芙形角色的五波街機戰：朝敵人吸氣取得火花、泡泡或葉旋屬性，再轉身吐出清場。

## Play

```bash
npx --yes serve .
```

觸控方向鍵／WASD 移動；吸入／J，吐出／K。

## Test

```bash
npx --yes vitest run
```

純 HTML/CSS/JavaScript，無建置步驟。素材資訊見 [ATTRIBUTION.md](./ATTRIBUTION.md)。
